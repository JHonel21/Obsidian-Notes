Deep Dive: Which to Choose?

|   |   |   |
|---|---|---|
|Task|Best Free Tool(s)|Why?|
|Research/Fact-checking|Perplexity|Provides real-time information with source links.|
|Long-form Writing|Claude|Produces more thoughtful text; great for reports, emails, or stories.|
|Coding|Claude/ChatGPT/Gemini|Claude 3.5 Sonnet (often available in free tiers) is top-tier for code. ChatGPT 4o is strong for general coding.|
|Data/Document Analysis|Claude|Excellent at analyzing PDF uploads and extracting key information.|
|Image Generation|Copilot/ChatGPT|Copilot offers free DALL-E 3 image generation.|
|Office Productivity|Copilot|Seamless integration with Microsoft 365 apps.|
|Brainstorming|ChatGPT/Claude|Both provide quick, creative ideas for projects or marketing.|

Summary of Strengths

- Claude: Human-like, nuanced, and handles large amounts of text.
- Perplexity: Accuracy, real-time data, and citations.
- ChatGPT: Versatility, speed, and widespread use.
- Copilot: Free, fast, and integrated with Microsoft 365.
- Gemini: Speed and integration with Google apps.
