# AGENTS.md

This file provides context about this Obsidian vault for AI agents.

## Vault Overview

This vault serves as a highly structured personal and professional knowledge base, balancing career management, technical hobbies, and personal development. A significant portion of the vault is dedicated to professional pursuits, specifically career tracking, interviewing, and vendor evaluations within the healthcare IT and technology sectors. Additionally, it contains extensive documentation for hands-on technical projects, such as 3D printing calibration, IoT hardware prototyping, and software development references.

## Organization

The vault is organized into clean, functional top-level directories based on domains of activity:

- **Career-Notes/**: The largest section of the vault, organized by specific target companies or projects (e.g., Aya Healthcare, Clearpath, Intelerad, SCHS). It features structured subfolders for interviews and chronological logs of calls and touchpoints.
- **3D-Printing/**: Highly organized by reference material, tuning profiles (categorized by nozzle size and filament brand/type), and active projects (e.g., FGC-9).
- **Inventions/**: Project-centric folders (such as `smart-hot-water-tank`) housing full system documentation including Bill of Materials (BOM), source code, and component architecture diagrams.
- **Coding/**: Technical reference notes covering programming languages, tools (VBA, JSON, Excel), and visualization tools like Mermaid.
- **Circle-of-Life/ & Stocks/ & Productivity/**: Personal growth logs, financial trading notes (focused on indicators like RSI and order types), and AI tools comparisons.

The vault leverages clear naming conventions for files to establish chronological order (e.g., `First-call`, `Second-Call-prep`, or dates like `06152026`) and technical specifications (e.g., `Point-6mm-Nozzle_Overture-PETG-Black`). Templates are used to standardize evaluations and workflows.

## User Preferences

The user prefers highly structured, technical, and objective information. They value precise, descriptive naming conventions and systematic documentation, as evidenced by their detailed filament profiles and step-by-step call logs. Avoid generic advice or conversational fluff.

Responses should prioritize clean formatting, utilizing bulleted lists, tables, and code blocks where appropriate. When discussing technical projects or systems, align with their structured approach by organizing information into logical components (e.g., Architecture, BOM, Code, Reference).
