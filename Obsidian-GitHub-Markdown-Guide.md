# Obsidian + GitHub Markdown Reference

A practical Markdown syntax guide that renders cleanly in **Obsidian** and remains readable and stable when synced to **GitHub**.

---

## File & Folder Naming

**Best practices**
- Use `kebab-case` or `snake_case`
- Avoid spaces and special characters
- Always use `.md`

```text
system-architecture.md
pocus_workflow.md

Headings: Obsidian treats the first # as the note title by default.
# H1 – Note Title
## H2 – Section
### H3 – Subsection
#### H4

Text Formatting
**Bold**
*Italic*
~~Strikethrough~~
`Inline code`

Tasklists
- [ ] To do
- [x] Done
